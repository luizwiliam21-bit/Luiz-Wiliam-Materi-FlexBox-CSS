Kuasai Tata Letak CSS Flexbox

Flexbox adalah model tata letak 1 dimensi (sebaris atau sekolom) yang mengelola distribusi ruang, perataan, dan ukuran elemen anak secara dinamis.

Bagian 3

Rangkuman Properti Flex Container

justify-content

Merapikan item di sepanjang Main Axis.

flex-start | center | flex-end
space-between | space-around | space-evenly

align-items

Merapikan item di sepanjang Cross Axis.

stretch (default)

flex-wrap & align-content

Membungkus baris dan meratakan multi-baris.

flex-wrap: wrap

Item akan otomatis berpindah baris baru saat kontainer tidak cukup.

align-content

Hanya aktif saat item membungkus (wrap). Merapikan baris-baris secara keseluruhan pada Cross Axis.

Bagian 4

Properti untuk Flex Items (Elemen Anak)

1. flex-grow, flex-shrink, & flex-basis

Trio properti yang mengatur fleksibilitas ukuran dimensi item.

flex-grow: [angka] default: 0

Menentukan rasio item membesar memperebutkan sisa ruang kosong.

grow: 0 (tetap)
grow: 1 (isi ruang)
flex-shrink: [angka] default: 1

Kemampuan item untuk mengecil jika kontainer menyempit. Nilai 0 mencegah item mengecil.

shrink: 0 (anti ciut)
shrink: 1 (menyesuaikan)
flex-basis: [ukuran | auto] default: auto

Ukuran awal elemen sebelum sisa ruang didistribusikan (mirip width pada row atau height pada column).

Shorthand yang disarankan:

flex: <flex-grow> <flex-shrink> <flex-basis>;

flex: 1; /* 1 1 0% */ flex: auto; /* 1 1 auto */ flex: none; /* 0 0 auto */ flex: 0 0 200px;

2. align-self & order

Menimpa perataan kontainer dan urutan tampil visual item.

align-self default: auto

Menimpa properti align-items dari induk khusus untuk 1 item tertentu saja.

center
self: start
self: end
stretch
order: [angka] default: 0

Mengubah urutan visual elemen tanpa perlu mengubah struktur HTML-nya.

A (HTML 1)
order: 2
B (HTML 2)
order: 1
C (HTML 3)
order: 3

Urutan tampilan visual menjadi: B → A → C.
